# Punch Up Games — Studio ADRs

Studio-wide Architecture Decision Records for Punch Up Games. These capture how we work, what we build on, and how we design — independent of any specific game, engine, or project.

**Start here: [000-index.md](000-index.md).** The index is the entry point. It carries the reading order, groups the ADRs by theme, and gives a one-line summary of each. Filenames are not the reading order.

If you're new, the index's *Values & Working Norms* cluster comes first — those set the context for everything else.

## What lives here

Only decisions that apply across every Punch Up Games project. Project-specific decisions belong in their own repositories.

## Conventions

- **Numbers are permanent.** Assigned once, never reused, never renumbered — a number identifies a decision for good.
- **Grouping and reading order live in the index**, not in the filenames.
- **Each ADR opens with its status, date, deciders, and an `Applies to` tag**, followed by Context, Decision, Reasons, Consequences, a `## Validation` section, and See Also. See ADR-0016 for what the tag and Validation section mean and how a reader is expected to use them — the index applies the same convention at a glance, without opening every body.
